# SlopeSafe

AI landslide early-warning and site-safety platform for Guwahati, built to scale across Northeast India.

## Problem
Landslides, slope failures, and road blockages are frequent in Northeast India, driven by heavy rain, fragile terrain, and unplanned hill cutting (SIH 2026, PS 26001, MDoNER).

## Study area
Guwahati and surrounding hills, including the road toward Meghalaya.

## Goal
Predict landslide risk, warn what happens if rain continues (8/24/48 h), and advise whether a site is safe to build on.

## Setup
```
pip install -r requirements.txt
python src/check_boundary.py
```
